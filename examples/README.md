# Examples

Realistic transcripts — the kind of prompts people actually send, the
guesses agents actually make, and what changes with NoAssume installed. Each
file stands alone.

| Example | The silent assumption |
| --- | --- |
| `docker-compose-port.md` | Publishing a database port on every interface |
| `greenfield-language.md` | Picking the model's favorite language for a greenfield tool |
| `upload-endpoint.md` | Choosing storage, limits, and auth semantics unasked |
| `bugfix-scope-drift.md` | Fixing a second bug nobody asked about |

Format: the prompt, what a bare agent ships, then the same request under
NoAssume — the questions, the answers, and the diff it produced.
