## NoAssume

This project uses NoAssume. Before creating, modifying, or deleting code,
configuration, or infrastructure, read and follow
`.agents/skills/noassume/SKILL.md` in this repository.

Core rule: never make a material implementation decision on an assumption.
If a decision is not specified by the user, proven by repository evidence, or
explicitly delegated, ask first. Maintain state in `.noassume/`; keep
`.noassume/local/` out of git.
