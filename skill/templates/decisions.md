# Decision ledger

One entry per decision in force. Class is one of: SPECIFIED, CLARIFIED,
PROVEN, DELEGATED, INFERENCE, ASSUMPTION, CONFLICT — see
`references/state.md`. Scope is `repository`, `task`, or `session`.

## Format

```markdown
### DEC-NNN — <short name>
- Class: <class>
- Decision: <what was decided>
- Source: <request quote | question ID | file:line | delegation scope>
- Scope: <scope>
```
